# Manuel développeur Munganga

Ce dossier est la source de vérité pour travailler dans le dépôt. Le `README.md`
racine explique comment lancer le projet ; les guides ci-dessous expliquent où
placer le code et comment livrer une fonctionnalité.

## Parcours conseillé

1. Lire [l’architecture](./ARCHITECTURE.md).
2. Lire le [guide frontend](./FRONTEND_GUIDE.md) ou le
   [guide backend](./BACKEND_GUIDE.md) selon la tâche.
3. Suivre le [workflow de développement](./DEVELOPMENT_WORKFLOW.md).
4. Consulter `/ui-kit` avant de créer ou styliser un composant.

En cas de désaccord entre un exemple ancien et ces guides, ouvrir une issue de
documentation avant d’introduire une nouvelle convention.
